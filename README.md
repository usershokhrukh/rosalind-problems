# Locating Restriction Sites

### Problem Description

We should compare the given DNA string with **reversed complement**, if they match, then print order of **palindrome** before length of it

In biology, bioinformaticians look for these sequences to identify where DNA can be cut, the "molecular scissors" called **Restriction Enzymes** help to avoid folding like "hairpin"

### Mathematical Logic

1. **Read DNA string** 
2. Check every **4-12** sequence with revp
3. print matched strings with order and length
